# 外出・外泊管理アプリ（短時間外出の版）

精神科病棟の入院患者の外出・外泊を記録し、帰院予定を過ぎたらiPadで知らせるアプリです。
この版では、短時間の外出をくり返す方の出発・帰院を、混む時間帯でも素早く記録できる仕組みを試します。

- 使う場所：https://heartcommit-design.github.io/gaishutsu-tanjikan/ をiPadのホーム画面に追加して使います。
- 位置づけ：ほかの外出管理アプリとは別のアプリです。データの保存先も別で、同じiPadに入れても混ざりません。
- データ：iPadの中だけに保存します。外部には送りません。
- 今の版：0.1.0
- 作った人：黒田 優

## ファイル
- `index.html` アプリ本体（1ファイル）
- `sw.js` `manifest.webmanifest` `icon-*.png` ホーム画面に追加して使うための部品
- `tests/` 自動テスト（`bash tests/run_tests.sh`）
- `tools/make_icon.py` アイコンを作る
- `docs/改善メモ.md` 課題と対応の記録
- `CLAUDE.md` 開発の決まりごと

テストや画面写真のデータはすべて架空です。
